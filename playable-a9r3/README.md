# MOMEY PLAYABLE A9R3

A9R3 is an isolated human-dependency pass over A9R2. It preserves the six-beat incident briefing, three-role training, event-driven Window 1 and Window 2 completion, live controls, operator voice, reconnect, deterministic outcomes, causal recap, and mobile-first layout.

The change is information topology:

- Common live UI contains the phase, authoritative timer, one static shared objective, and system-level events only.
- Operations owns exact power routing, reserve, close feedback, and close progress.
- Rescue owns exact trolley position/heat/checkpoints, Lin Rui's boundary, and secure state.
- Safety owns exact pressure/trend, brace state/stamina, Gao Cheng exposure, and the final pressure-wave window.
- Rescue and Safety readiness never appear as digital booleans on Operations' phone.
- Role-local milestone events are shareable aloud but are not automatically mirrored.

One bounded room-level pressure-wave family is selected deterministically when the room is created. It has three authored timings, is fixed truth before play, and is visible first to Safety. It adds no round or incident profile. Premature gate pulls rebound, add mechanical strain, and enter a short cooldown; one mistake is recoverable, while repeated blind attempts have consequences.
