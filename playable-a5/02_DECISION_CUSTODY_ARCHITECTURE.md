# Decision-Custody Architecture

| Custody | Owner | Capability |
| --- | --- | --- |
| Open-exchange progression | Command | Presses once after all three speak |
| Verification selection | Team, executed by Command | A/B draft, change, confirm, lock |
| Verification A | Rescue | Two-step authorization gate and west-side scan |
| Verification B | Safety | Two-step authorization gate and east-gate test |
| Post-check reflection | Humans | Spoken: who changed and why |
| Final moral decision | Team | Rescue and Safety each state choice and reason |
| Final execution | Command | Draft, change, confirm, lock |
| Consequence | Command screen | One shared viewing moment |

Command is a UI custodian, not a superior moral authority.
