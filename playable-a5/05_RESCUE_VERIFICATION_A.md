# Rescue Verification A

Rescue owns the west-side scan. The action is available only as a human-authorized specialist capability:

1. hear Command announce A;
2. open a reversible final-check gate;
3. execute the single west-side pulse;
4. read the detailed result;
5. report it aloud.

The first click never reveals the result. Rescue has no final Close/Hold control and no consequence.
