# Mismatch and Misclick Test

| Attack | Result |
| --- | --- |
| Rescue opens A before verbal authorization | First click only arms a warning gate; no result |
| Safety opens B before verbal authorization | First click only arms a warning gate; no result |
| Team says A but Safety accidentally opens B | B remains unrevealed; cancel returns safely |
| Command changes A → B → A before confirmation | Draft changes; confirm locks A |
| Command changes Close → Hold before confirmation | Draft changes; confirm locks Hold |
| Rescue/Safety try to produce final outcome | No final controls or consequence exist |

Ordinary one-click mistakes do not reveal either specialist result. Intentional rule-breaking on independent devices is not cryptographically prevented and remains a known static limitation.
