# Command Custody

Command retains the timeline tool and gains only procedural controls:

1. mark the three-person exchange complete;
2. draft/change/confirm one verification;
3. announce the correct specialist handoff;
4. acknowledge the specialist has verbally reported;
5. show the final confirmed/unknown summary;
6. draft/change/confirm the action;
7. show the single consequence.

Detailed specialist results never appear automatically on Command. Before final confirmation, Rescue and Safety must each state which action they support and why.
