# MOMEY PLAYABLE A2

這是一個獨立的靜態三人原型，入口在 `playable-a2/index.html`。它把海岬防洪站的共同序章、三個角色介面、角色行動、公開交換、一次有限查證、共同決定與四種後果放在同一個本地流程裡。

## 開始

直接用瀏覽器開啟 `index.html`，或從 repo 根目錄啟一個靜態檔案伺服器：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

再開啟 `http://127.0.0.1:8765/playable-a2/`。三支手機的角色頁是 `role-1.html`、`role-2.html`、`role-3.html`。

## 操作邊界

- 三個角色是同一支事故應變小組，可以把知道的內容公開說出來。
- 每個角色的按鈕只代表該角色能調用的備援鏈路；結果會用同一套「來源／時間／內容／還不能確定」證據卡呈現。
- `localStorage` 只保存這支手機目前角色的 action 與口頭交換確認；`teamReady` 跟著該角色的 `momey-a2:seat:*` 保存。查證與決定則留在同一支手機自己的 `momey-a2:shared`。
- 查證草稿、查證確認、決定草稿、決定確認和後果分開保存。重新整理不會清掉進度；「重新開始」會清除 `momey-a2:` 前綴的本地狀態並回到入口。
- 沒有後端、帳號、付款、分析、即時倒數或外部服務。每支手機不會偵測另外兩支；玩家完成自己的 action、口頭交換三份結果後，要在自己的手機確認「三個角色都完成操作，也把結果說給彼此了」，才會解鎖本機查證流程。

## 固定故事

事故發生在海岬防洪站的颱風夜。18:40 林芮進入西側維修隧道，高承查看東閘手動撐架；18:47 海水進水管破裂，主電力和中央遙測同時失效；18:48 三個備援鏈路接手同一個事故時刻。剩餘電容只能做一次高能診斷，隊伍必須在「立即封閉」與「維持 95 秒」之間共同承擔後果。

## 測試

```powershell
node --test playable-a2/tests/contract.test.mjs
```

靜態合約測試會檢查故事理解、三角色語意對齊、證據格式、角色行動、三個隔離 session 的本機 readiness gate、查證草稿/確認鎖定、四分支、刷新/重置、行動版 CSS、禁止基礎設施引用與保護路徑未變更。

A1.2 位於 `playable-a1/`，本路由不讀取也不修改它的 runtime。
