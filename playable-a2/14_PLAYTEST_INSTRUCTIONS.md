# Playtest Instructions

## 事前

1. 三位玩家同室，各自拿一支手機並開自己的角色 route；不要用同一個 storage profile 模擬三支手機的完成狀態。
2. 先一起開 `playable-a2/index.html`，只看共同序章，不要先讀 review docs。
3. 各自選事件指揮、救援聯絡、結構安全；每人只在自己的角色頁按一次 action。

## 遊戲中

1. 每個人把自己的 evidence card 讀給隊友聽，說出來源、時間、內容和還不能確定。
2. 三份結果都口頭公開後，討論兩個未知，不需要安排固定發言順序。
3. 每位玩家在自己的手機按「三個角色都完成操作，也把結果說給彼此了」。這是本機確認，不是手機偵測到另外兩支裝置。
4. 在 A/B 卡片上先選草稿，確認前可以換；按「確認這次唯一查證」後，只看那一張結果。
5. 讀共同摘要，討論「立即封閉」或「維持 95 秒」；先選 draft，再按確認。
6. 一起讀後果中的三段客觀結果，回答最後一句人類問題。

## 回歸測試

- 刷新角色 action 後確認結果仍在。
- 刷新本機 `teamReady` 後確認查證仍解鎖；reset 後確認它被清除。
- 用三個隔離 storage context 驗證每席只需自己的 seat key；在同一裝置換到未操作角色時不得解鎖查證。
- 刷新查證草稿、查證確認、final 草稿、final 確認後確認各自保存。
- 點「重新開始」後回到入口，且進度消失。
- 用 390×844 和 412×915 檢查沒有橫向捲動，按鈕可用手指操作。

禁止把此 prototype 當成實際救援建議；這是固定故事真相的本地玩法測試。
