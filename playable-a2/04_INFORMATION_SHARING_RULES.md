# Information Sharing Rules

## 唯一的資訊規則

你們是同一隊。知道的都可以說；每個人能做的事不同。玩家可以讀出、描述、比較和質疑任何自己已看到的內容，不需要編造、隱瞞或拒絕回答。

## 為什麼公開後仍然有遊戲

公開分享只會把三支 action 的結果放到同一張桌上，不會替隊伍補上 action 自己沒有的證據邊界。分享後仍有兩個重要未知：西側人與路線是否能在現在被救出，以及東閘撐架是否能撐滿 95 秒。剩餘電容只能選一種查證，因此資訊完整不等於答案完整。

## 每個階段的人類行動

| 階段 | 手機做什麼 | 人接著做什麼 |
| --- | --- | --- |
| 角色行動 | 讓特定鏈路回傳一張 evidence card | 把來源、時間、內容和邊界說給隊友 |
| 公開交換 | 顯示三份必要貢獻與本機確認；不顯示遠端完成狀態 | 各自說出證據，確認三份都已交換，再按本機確認 |
| 有限查證 | 讓隊伍草稿選 A 或 B，確認後才顯示結果 | 先說明要捨棄哪個未知，再按確認 |
| 共同決定 | 並列兩個沒有道德標籤的方案 | 交換理由，形成草稿，再按共同確認 |
| 後果 | 顯示實際發生與後來確認 | 用一句話把經驗交給下一個班次 |

## 本地狀態的界線

沒有 backend，所以不同實體裝置不會自動同步，也不會互相回報 action 完成。每位玩家必須先完成目前角色自己的 action；三人把結果說給彼此後，各自在自己的手機按「三個角色都完成操作，也把結果說給彼此了」。這個動作只把 `teamReady` 寫進目前角色自己的 seat state，並在該手機解鎖共同證據與有限查證。

`momey-a2:shared` 也只是該手機本地的查證／決定狀態，不是跨裝置共享服務。測試以三個隔離 storage context 分別跑三席；每席不需要、也不能依賴另外兩個 seat key。
