# Change-of-Mind Synthetic Test

| Case | Local reconsideration states | Can discuss and reach final? |
| --- | --- | --- |
| One changes | Changed / Unchanged / Unchanged | YES |
| Multiple change | Changed / Changed / Unchanged | YES |
| Nobody changes | Unchanged / Unchanged / Unchanged | YES |
| One remains unsure | Still unsure / Changed / Unchanged | YES |

The runtime does not require a changed state. It also does not infer a new Close/Hold preference from “Changed.” The meaning must be spoken by the player.

This preserves the difference between reflective gameplay and survey collection: the phone stores no score, sends no event, draws no chart and shows no group statistics.
