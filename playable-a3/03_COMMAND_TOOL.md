# Role 1｜事件指揮：時間線重建

## 玩家看到什麼

共同 `0–95 秒` 軌上有兩段流程：`遠端封閉 20 秒` 與 `救援清線 95 秒`。流程卡與終點按鈕分開，手機上不需要 drag。未對齊時兩條流程都使用中性待放置長度，不先畫出相對終點或衝突答案。

## 操作

1. 點「遠端封閉」或「救援清線」。
2. 再點該流程的終點：封閉選 `t=20 秒`，清線選 `t=95 秒`。
3. 若點錯，顯示溫和提示並保留可重選狀態。
4. 兩段都正確前，完整 evidence 不出現。
5. 完成後，兩條 bar 才縮放到各自終點，並明示 `t=20 秒封閉切斷路線`、`t=95 秒救援完成`。

Sol High 初次攻擊曾發現工具前置備註與 bar 長度已提前給出衝突，判為 Core P1。最終版把推論延後到兩段完成後，並由 contract test 拒絕舊的預揭文字。

## 證據結果

來源／時間／內容／還不能確定沿用 A2 格式；結果只由兩段對齊完成後產生。東閘撐架承載仍是未知。
