# A7 真實測試說明

準備：3 人、同一房間、一人一機。不要由 creator 先解釋故事或詞彙。

1. 只在一支手機開序章聲音，三人一起看完八段；其他手機可靜音。
2. 請三人分別開角色 1、2、3 的不同連結，但使用同一 URL seed。
3. 每人選一個問題；不要互看手機的私人結果。
4. 看到兩點結果後，用自己的話告訴隊友。
5. 三人都說完後，各自按「三人都說完了」。
6. 討論共同選項；三支手機先選同一項，再按 group confirmation，最後執行。
7. 記錄首次理解，不提示正確答案。

觀察題：誰是林芮？誰是高承？各在哪？要關什麼？關上會讓什麼不能通？等 95 秒危險往哪裡走？每個按鈕按下去會做什麼？是否需要 creator 介入？

測試後不要把不完整印象當成 acquisition 或商業證據；只回報理解缺陷。
