# 真實首次遊玩回饋

證據來源：A6R 版本的真實 3 人首次遊玩，由 owner 轉交。A7 未新增真人測試，不能把後續合成測試稱為真人證據。

觀察到的核心問題：

1. 玩家無法在進角色前清楚說出林芮、高承、兩人的位置與三人小組任務。
2. 玩家不清楚實際要關的是哪一個物理物件，以及關上後哪條救援路線會失效。
3. 既有文字包含較多系統／工程語彙，第一次讀取的理解成本過高。
4. 語音說「查哪一塊」，文字卻說「補哪一塊」，形成核心 P1 的語意漂移。
5. 診斷按鈕與最後選項沒有在按下前充分說清楚實際作用。

A7 的目標只修復這些已觀察到的理解失敗；不據此宣稱樂趣、重玩性或商業需求已獲驗證。
