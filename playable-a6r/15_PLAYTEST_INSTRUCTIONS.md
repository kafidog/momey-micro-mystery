# A6R Playtest Instructions

1. 三人同室、一人一機，從入口各開一支不同角色連結。
2. 不向玩家解釋 seed、profile 或 runtime architecture。
3. 角色首次開啟時，只問玩家能否回答「我負責什麼」「現在要做什麼」並點「開始」。
4. 每席選一個 diagnostic，確認前刻意改選一次。
5. 看到結果後，把 found、means、仍不知道說給隊友。
6. 交換完成後共同選 close 或 hold；確認前改選一次。
7. 觀察 drawer 是否只呈現已揭露資料。
8. 測試 refresh、正常 MP3 播放、刻意缺檔時的字幕 fallback、troubleshooting reset。
9. 紀錄困惑與實際畫面，不將未驗證主觀印象寫成 PASS。
