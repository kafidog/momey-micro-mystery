階段 0 / 準備

先留在自己的畫面。

你是人員訊號。這一席看見的是裝置上的人類來源訊號，以及它能不能支持某種推論。不要把手機交給別人；讀完一張卡，就抬頭說出你認為重要的部分。

01
開始後 60 秒內先看私密資料三人各自讀自己的第一張卡，再開始交換。按鈕只推進你自己的手機。

階段 1 / 第一個私密視角

你知道一個不能只靠系統狀態回答的訊號。

只把「這張卡改變了什麼」說給另外兩席，不要把手機遞過去。

私密證據 02 / 人類來源

人類生理樣態，但映射尚未校驗

監測到類似人類生理訊號，暫時與 P 的通道及位置 C 關聯；relay checksum 與裝置映射尚未校驗。它仍可信、值得討論，但不是已查證的 P 穿戴裝置、即時人類與 Sector C 完整連結。

說
說出：人類樣態和 P 的通道、位置 C 暫時有關，但映射尚未校驗。不要把「仍有訊號」說成「已安全離開」。

階段 2 / 交換與第二次貢獻

現在補上訊號持續的含義。

先聽另外兩席，再把這張卡的邊界說出來。這是你的第二次必要貢獻。

私密證據 05 / 持續性

持續性仍支持求救可能

07:19 後仍有短段連續訊號；變化符合求救或壓力反應的可能性，但 relay checksum 與裝置映射仍未完成校驗，不構成安全撤離的確認。

說
說出：持續訊號支持「可能仍在內」，但來源映射仍可信而未校驗。讓另外兩席知道你的信號強度，也知道你不能確定什麼。

階段 3 / 重構

「0 confirmed personnel」不是「物理上沒有人」。

把前兩段資料放在一起重新讀一次：P 先合法進場，後來確認服務中斷，而且沒有 P 的確認離場。系統沒有說謊；它只報告目前沒有任何人能被確認。

重構規則0 confirmed personnel = 確認資料中斷後的目前狀態，不是 Sector C 已被證明為空。
問
三人先互相回答：這個 0 現在能證明什麼，又不能證明什麼？確認人員狀態與物理真相不是同一件事。

階段 4 / 限定查證

三人先口頭選一項，只能查證一項。

每支手機最後都選同一項。兩項都會讓一部分不確定變清楚，但都不會替你們做最後決定。

尚未選擇。三人先口頭決定只查證一項，再在各機選同一項。

查證結果 A / 只給你看

穿戴裝置 checksum 與即時生理連結

relay checksum 與裝置映射完成校驗：即時人類生理訊號確實來自 P 的穿戴裝置，位置在 Sector C。

這是 A 的來源片段；撤離路徑仍未被證明，另外兩席的時間線與環境邊界仍要分享。

查證結果 B / 只給你看

污染干擾與人員暴露邊界

回覆指出延後時污染可能干擾訊號，並讓人員暴露邊界變得更窄。

這是 B 的人員邊界片段；封鎖模型校準仍由另外兩席補上，不指定哪個個體一定受害。

階段 5 / 口頭共識與承諾

先說出同一個決定，再各自在手機上確認。

先不要按。先完成三輪口頭協議，再由三人共同決定「立即封鎖」或「延後封鎖」，最後每支手機選相同的兩個選項之一。

共識
手機不會替你同步。一致是人類先說出來，再由三支手機各自留下相同承諾。
  1. 第一輪／人員訊號先說若立即封鎖，人會失去什麼？
  2. 第二輪／封鎖風險再說若延後封鎖，下游會承擔什麼？
  3. 第三輪／事件指揮最後重述只重述兩個代價，不替全組決定。

階段 6 / 後果與完整結束

承諾已送出。讀完結果，再回到彼此身邊。

立即封鎖

封鎖在污染跨過邊界前生效，下游擴散被阻止。

P 留在封鎖側；救援窗口關閉，訊號中止，P 無法被救出。這不是好結局，也不是壞結局；它是你們保住的東西與失去的東西。

延後封鎖

P 在窗口內被救出，但污染越過邊界。

下游區域被封區並出現暴露與實際代價。這不是好結局，也不是壞結局；它是你們保住的東西與失去的東西。

你們查證的是人類來源可信度；它改變了你們如何理解訊號，不會改寫已發生的授權、服務中斷或風險。

你們查證的是封鎖模型；它改變了你們如何理解延後的風險，不會改寫 P、訊號或已發生的服務中斷。

談
三人一起說：我們保住了什麼？誰承擔了什麼？這一輪已完成；沒有分數，也沒有正確按鈕。
