# Playtest instructions

## Setup

1. Start a read-only static server at the repository root.
2. Open `/playable-a1/` on one device or share the three seat links privately.
3. Put three people in the same physical room.
4. Each person opens one seat on their own phone; do not show the screen to another player.
5. Agree that each person will speak after reading each private card.

## Run

- Seat 1 uses `seat-1.html`.
- Seat 2 uses `seat-2.html`.
- Seat 3 uses `seat-3.html`.
- At Stage 3, ask each player to explain what `0 confirmed personnel` does and does not prove.
- At Stage 4, discuss and choose A or B verbally before each phone selects it.
- At Stage 5, discuss and agree verbally before each phone selects the identical commitment.
- Read the complete consequence aloud together.

## Technical checks

- Refresh each phone once at Stage 2, Stage 4, and Stage 5; verify approximate stage recovery.
- Use the two-step reset only after the complete end; verify one seat reset does not alter the other seats.
- Check desktop, iPhone-like narrow, and Android-like narrow widths for overflow and reachable buttons.
- Record console errors and DOM/visual evidence outside the repository; do not create a delivery pack in this round.

## Evidence boundary

This is a synthetic/technical walkthrough. Do not convert it into human-fun, demand, WTP, E3, or E4 evidence.
